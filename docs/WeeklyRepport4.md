This week was educational, As I was working on Prims algorithm the lack of initial planning and my mediocre grasp on C# caught up to me.
I spent the entirety of Wednesday refactoring and rewriting everything from scratch, basing the new structure on that of vazgriz's DungeonGenerator. 
Whilst I initially did not want to look at any other code for the same thing, I must admit that it proved very educational and my grasp on C# especially increased quite a lot.

## Note
Whilst the other project was used as inspriation **NO CODE WAS COPIED**, all code was written by me.

## What did I learn?
- You can overwrite operators on classes in C#, this proved very helpful in comparisons, and I would not have learnt this unless I looked at the other project.
- Being able to easily add T[x, y] getters and setters to classes was something I would never intuitively have guessed you could do.
- Class nesting, this was something I wasn't aware of initially. But it proved quite nice for creating classes such as Edges for different graphs / algorithms.
- It is better to plan ahead, I had to rewrite my own types multiple times before I started the refactor, and now that I knew what I needed for each step I only had to create the types once.
